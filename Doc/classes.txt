Idle class compiler

`idlec [--macro NAME=PATH ...] INPUT.idle ... -o OUTPUT.wat` combines all
inputs into one validated WebAssembly GC text module.  Supplying a subclass
before its parent is allowed.  This is compile-time linking: separately
compiled Wasm modules cannot extend one another's GC struct types directly.
Every input contains one unnamed (module ...) form; the compiler flattens their
fields in input order before resolving classes.

Declarations:

  (class Name
    (extends Parent)
    (field immutable-name i32)
    (field mutable-name (mut i32))
    (method read ((argument i32))
      (result i32)
      wat-instruction ...)
    (override inherited-method ((argument i32))
      (result i32)
      wat-instruction ...))

  (export-new Name)
  (export-method Name read)
  (export-func raw-wat-function)

Method bodies contain WAT instruction S-expressions and receive `$this` plus
their named parameters.  `classes:get`, `classes:set`, `classes:call`,
`classes:return-call`, and `classes:super-call` lower field and method
operations.  Other top-level forms are copied as raw WAT module fields.

Overrides repeat the complete inherited parameter and result signature.  The
compiler requires an exact match before installing the overriding
implementation in the inherited method slot.

`typed-defun` uses the same signature-list shape as `defun`, but checks a small
source language before lowering it to WAT:

  (typed-defun $length (($list List) i32)
    (let $cursor List $list)
    (let $length i32 0)
    (while (i32.eqz (.is-empty $cursor))
      (set $cursor (.tail $cursor))
      (set $length (i32.add $length 1)))
    $length)

Parameters, the single result, and locals are explicitly typed.  Checked types
are `i32` and non-null class names such as `List`; class references flow to
ancestor types.  `(.method receiver arguments...)` infers the method slot from
the receiver's declared type and lowers through the existing virtual
dispatcher.  The checked body also supports integer literals, direct function
and constructor calls, `i32.add`, `i32.sub`, `i32.eqz`, `let`, `set`, and
`while`.  Fields and raw method bodies retain the explicit `classes:*` forms.
Use ordinary `defun` for unchecked WAT bodies.

For example:

  node src/idlec.mjs \
    example/classes/offset-counter.idle \
    example/classes/counter.idle \
    example/classes/main.idle \
    -o /tmp/counters.wat
